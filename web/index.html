# Flop Deviation from even Equity

Two known hands leave 48 unseen cards, so there are C(48,3) = 17,296 possible flops. Each of those leaves 45 cards, so there are C(45,2) = 990 turn-and-river runouts. Every one is dealt out and scored — about 34 million hand evaluations per matchup. A chop counts as half a win to each player, so the two equities always sum to 100%.

Nothing here is sampled or simulated, so the same hands always give the same answer. The engine is the project's C++ core compiled to WebAssembly, running entirely in this tab — the same code the command-line version uses.
